# ATTRIBUTION.md — every asset, where it came from, and under what terms

**The Lost · walker-the-lost-TiantongZhang · Tiantong Zhang ·
`zhang.tiant@northeastern.edu`**

One place to answer "whose is this?" for anything that ships. `SOURCES.md` says
where every *file* came from and is the longer document; this one is the
licence question only, and it covers the game and the film separately because
they have different answers.

**The short version.** Nothing in the game was downloaded and nothing in the
game was generated by a model. Every texture and sprite is written by a
committed script, every 3D model is the author's own Blender work from
Assignment 3, and there is no asset pack, no marketplace download and no
third-party audio anywhere under `godot/`. The film is different in exactly one
respect, stated plainly below: its narration is a text-to-speech model's output.

## 1. Game assets — everything under `godot/`

### 1.1 Textures and sprites: written by code

The assignment allows this explicitly — *"Textures written by code are fine;
show the code."* The generator is committed, so the provenance **is** the
source: run the script and you get the same bytes.

| File | Written by | Licence |
|---|---|---|
| `godot/assets/textures/stone_albedo.png` | `godot/tools/write_textures.gd` | Mine. Nothing to license. |
| `godot/assets/textures/wetness_mask.png` | same | Mine. |
| `godot/assets/textures/hint_bands.png` | same — a 3 × 1 PNG whose texels are the greys 64, 128, 192, imported lossless with no mipmaps | Mine. |
| `godot/assets/sprites/spike_trap.png` | `tools/make_sprites.py` | Mine. |
| `godot/assets/sprites/spike_trap_fired.png` | same | Mine. |
| `godot/assets/sprites/player.png` | same — 16 × 28 px, 1.75 m at 16 px = 1 m | Mine. |
| `godot/assets/sprites/floor_tile.png` | same — flat `#16242B` | Mine. |

`tools/make_sprites.py` asserts the two prediction pixels that
`CHANGE-BRIEF.md` §6 fixed **before** anything was drawn, and fails if a later
edit moves them. The predictions drove the art rather than describing it.

**No normal map**, and that is a deliberate cost of this choice:
`CHANGE-BRIEF.md` §8 says so in the specification rather than discovering it
afterwards. Code-written textures forgo the Poly Haven `_nor_gl` / `_nor_dx`
calibration pair, so Step 3's curl check does not apply to this submission.

### 1.4 Audio in the game

**None.** The slice has no music and no sound effects. That is a boundary
Assignment 5 drew, not an omission: `walker-ninja`'s audio was deliberately not
carried across, and the port is Assignment 6's first work.

### 1.5 Starter code

**None in this repository.** The Assignment 1 starter,
[walker-jumpman](https://github.com/nikbearbrown/walker-jumpman), is credited in
`walker-ninja-TiantongZhang`, where it was actually used. Its `SOURCES.md`
notes that public availability is not a licence grant for its inherited art,
and none of that art is here.

### 1.6 Generative models used for game assets

**None.** No image model, no 3D generator, no audio model produced any file
under `godot/`. There is therefore no model, version, prompt or terms to record
for the game — and no prompt in this repository names a living artist, a brand,
a copyrighted character or existing music.

## 2. The film — `youtube/claude-liam-walker-the-lost-gamedev/`

### 2.1 One generative model is used, and it is the narration

| | |
|---|---|
| **Model** | **Kokoro**, a neural text-to-speech model, run **locally** |
| **Voice** | `am_onyx` |
| **Run by** | the course toolkit's `runtime/scripts/generate_audio_kokoro.py` |
| **Cost** | none — local inference, no paid call, no cloud call |
| **What it generated** | the spoken audio of 17 beats (`mp3/beat-*.mp3`). B14, the outro, is intentionally silent under its jingle. |
| **What it did not generate** | the words. Every sentence it speaks is written by hand in `beat_sheet.json` as `narration_text` and is checked line by line in `FACTCHECK.md`. The model supplies a voice and nothing else. |

This is the one place where "no generative model" would be false, which is why
it has its own row rather than a footnote. The claim that holds without
qualification is the narrower one: **no generative model produced any asset in
the game.**

### 2.2 Every frame is drawn by committed code

| Beat kind | Drawn by |
|---|---|
| B03, B05 — gameplay | Real engine captures, framed by `scripts/frame_footage_beats.py`. No pixel value of the capture is altered. |
| B03A, B07, B09, B11, B11B — evidence cards | `scripts/compose_lost_evidence.py`, over grids laid out by `scripts/compose_a5_extras.py`. Every number on them is read out of the recorded report at build time and drawn verbatim. |
| B00, B01, B02, B04, B06, B08, B10, B11A, B12, B13, B14 | The course toolkit's Remotion components |

**No image model produced any frame of this film.** No stock footage, no stock
photography, no third-party illustration.

### 2.3 The course toolkit, and what belongs to it

The film is built with **`brutalist.art`**, Nik Bear Brown's course toolkit
(`../brutalist.art-main`, not vendored into this repository). The locked outro
card `ClaudeTitleOutro` supplies, from the toolkit and seeded deterministically
from the reel slug:

- the **mascot** on the outro card,
- the **jingle** under it — the only music anywhere in the film,
- the `@NikBearBrown` brand mark and the Claude-palette brand tokens.

These are the instructor's, not mine. I added nothing to them and changed
nothing in them; `OUTRO-LOCK.md` in the toolkit governs them. The film carries
no other music and no other audio besides the narration above and the engine
audio that came through the capture.

### 2.4 Typefaces

## 4. How to check all of this

1. `tools/make_sprites.py` and `godot/tools/write_textures.gd` — run them; the
   textures and sprites come back byte for byte, and the sprite script asserts
   `CHANGE-BRIEF.md` §6's prediction pixels.
2. `git log --format='%h %an' -- godot/shaders/` — four commits, one author.
3. `git diff --stat godot/shaders/` across any agent commit — empty.
4. `scripts/compose_lost_evidence.py` — every figure on every evidence card is
   read from a report file, so changing a report changes the card.
5. `find godot -name '*.mp3' -o -name '*.ogg' -o -name '*.wav'` — empty. The
   game has no audio to attribute.
