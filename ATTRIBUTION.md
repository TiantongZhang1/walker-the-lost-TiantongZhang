# ATTRIBUTION.md — every asset, where it came from, and under what terms

**The Lost · walker-the-lost-TiantongZhang · Tiantong Zhang ·
`zhang.tiant@northeastern.edu`**

One place to answer "whose is this?" for anything that ships. `SOURCES.md` says
where every *file* came from and is the longer document; this one is the
licence question only, and it covers the game and the film separately because
they have different answers.

**The short version.** Nothing here was downloaded from a marketplace or an
asset pack. Up to the `a5` tag nothing in the game was generated by a model
either; the Assignment 6 port changed that and this file was rewritten rather
than left standing. As of `a6` the game contains:

| | |
|---|---|
| Written by committed code | every texture and sprite, the dungeon backdrop, and all four sound effects |
| The author's own Blender work | the three `.glb` from Assignment 3 |
| **Generated by a model** | the five character poses (**GPT-6**) and the music bed (**Suno v6-mini**) |

**Two consequences, stated up front rather than buried in a table.**

1. This repository can no longer say it contains no generated assets. It
   contains two kinds, both carried from `walker-ninja-TiantongZhang` with
   their provenance, and both recorded in full below.
2. **The music is licensed for personal and non-commercial use only.** Suno
   retains ownership of it. A graded course submission and an unmonetised
   film are inside that grant; selling, monetising or commercially releasing
   this project while that track is in it would not be. §1.7 has the
   reasoning and the date it was checked.

## 1. Game assets — everything under `godot/`

### 1.1 Textures and sprites: written by code

The assignment allows this explicitly — *"Textures written by code are fine;
show the code."* The generator is committed, so the provenance **is** the
source: run the script and you get the same bytes.

| File | Written by | Licence |
|---|---|---|

`tools/make_sprites.py` asserts the two prediction pixels that

**No normal map**, and that is a deliberate cost of this choice:
`CHANGE-BRIEF.md` §8 says so in the specification rather than discovering it
afterwards. Code-written textures forgo the Poly Haven `_nor_gl` / `_nor_dx`
calibration pair, so Step 3's curl check does not apply to this submission.

### 1.4 Audio in the game

Silent up to `a5` by a boundary Assignment 5 drew. The port is Assignment 6's
first work, exactly as A5's limitation 1 said it would be.

| File | Origin | Licence |
|---|---|---|
| `godot/assets/sfx-trap.ogg` | **Written by code** — `scripts/synth_placeholder_sfx.py`, closed-form waveforms plus one noise array from numpy's PCG64 at **seed 727001**. Re-running it reproduces the WAVs byte for byte. | Mine. |
| `godot/assets/sfx-death.ogg` | same | Mine. |
| `godot/assets/sfx-jump.ogg` | same — **written but not wired**; see below | Mine. |
| `godot/assets/sfx-slash.ogg` | same — **written but not wired**; see below | Mine. |
| `godot/assets/music-loop.ogg` | **Suno v6-mini.** §1.7. | **Suno's, not mine** — personal and non-commercial use only. |

**These four effects are placeholders and say so in their own generator's
docstring.** They are arithmetic, not generated audio, and they do not satisfy
any "generate sound" requirement. The disclaimer was written in walker-ninja
and still applies.

Two of the four are unwired: `sfx-jump` needs a signal `player.gd` does not
emit, and emitting one would mean editing a file Assignment 5's `CLAUDE.md`
puts out of scope; `sfx-slash` belongs to a combat move this slice does not
have. They are on disk because the script that writes them writes four.

The OGG files are **not** byte-identical across runs — an Ogg page header
carries a stream serial that ffmpeg picks at random and exposes no flag to
pin. The decoded PCM is identical. The reproducible artefact is the waveform.

### 1.7 The music, and the one licence limit in this repository

| | |
|---|---|
| File | `godot/assets/music-loop.ogg`, 31.0 s, 154 kbps |
| Model | **Suno `v6-mini`** |
| Generated | 2026-10-01, on the **free Basic tier** |
| Seed | **None — Suno exposes none.** The prompt reproduces the request, not the output. |
| Prompt, verbatim as Suno's library records it | `driving 124 bpm, pulsing bass with tight muted percussion, urgent and forward-moving, loop for a side-scrolling platformer, metal walkways and machinery, near-future industrial, no vocals, seamless loop` |

**Who owns it.** Suno does. Their Help Center,
<https://help.suno.com/en/articles/2416769>, puts the test in one sentence —
*"was I subscribed when I made the song?"*:

> If you were subscribed with a Pro or Premier plan when the song was
> created, you are considered the owner of the song. […] If you are using the
> free version of Suno (our Basic tier), we retain ownership of the songs you
> generate, but you are allowed to use those songs for non-commercial
> purposes.

Ownership turns on the plan **at creation time**, not on how the file was
later obtained. This track was generated on the free Basic tier with no Pro
or Premier subscription at any point; a single-download pack bought
afterwards purchased a download, not a licence upgrade.

**So:** the permitted use is personal and non-commercial, which a graded
course submission is. **The limit, stated rather than left to be inferred:
this project must not be sold, monetised or commercially released while that
track is in it.** A film of it posted publicly and unmonetised is still
non-commercial use; a monetised upload would not be.

**Scope of what was checked:** the Help Center article above, read
2026-10-06 in walker-ninja. The Terms of Service themselves were not read in
full. Nothing above rests on them.

**Removing it is one line** — `MUSIC` in `godot/game/room_audio.gd` — if that
limit ever stops being acceptable.

### 2.1 One generative model is used, and it is the narration

| | |
|---|---|
| **Model** | **Kokoro**, a neural text-to-speech model, run **locally** |
| **Voice** | `am_onyx` |
| **Run by** | the course toolkit's `runtime/scripts/generate_audio_kokoro.py` |
| **Cost** | none — local inference, no paid call, no cloud call |
| **What it generated** | the spoken audio of 17 beats (`mp3/beat-*.mp3`). B14, the outro, is intentionally silent under its jingle. |

Up to the `a5` tag this was the **only** generative model anywhere in the
project, and that is why it has its own row rather than a footnote. It is no
longer the only one: the Assignment 6 port brought GPT-6 character poses and
a Suno music bed into the game itself, recorded in §1.6 and §1.7. The claim
that still holds without qualification is narrower again: **no generative
model produced any texture, sprite sheet or 3D model in this repository.**

## 4. How to check all of this

1. `tools/make_sprites.py` and `godot/tools/write_textures.gd` — run them; the
   textures and sprites come back byte for byte, and the sprite script asserts
   `CHANGE-BRIEF.md` §6's prediction pixels.
2. `git log --format='%h %an' -- godot/shaders/` — four commits, one author.
3. `git diff --stat godot/shaders/` across any agent commit — empty.
4. `scripts/compose_lost_evidence.py` — every figure on every evidence card is
   read from a report file, so changing a report changes the card.
5. `find godot -name '*.mp3' -o -name '*.ogg' -o -name '*.wav'` — empty. The
   game has no audio to attribute.
